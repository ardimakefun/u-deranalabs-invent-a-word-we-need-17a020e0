Entry for the make.fun bounty [Invent a Word We Need](https://make.fun/c/u-deranalabs-invent-a-word-we-need-17a020e0): coin one new English word and define it in a single line of at most 140 characters.

## The entry

> "Sendgret (n.): the instant regret of spotting a typo the second after you hit send."

83 characters, one line.

## Run

```sh
node main.ts
```

Writes the text to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`), with a fail-fast gate (1–140 characters, not only whitespace, single line) checked both before writing and against the bytes read back from disk. Deterministic: every run writes the exact same bytes.
